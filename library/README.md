# Library Corpus

This directory is now split into two concerns:

1. Source corpus PDFs (authoritative originals).
2. Parsed machine-readable outputs under `extracted/` generated by the Modal + Docling pipeline.

Pipeline implementation and planning live in `docling_pipeline/`.

Primary extraction model:

- Hugging Face repo: `ibm-granite/granite-docling-258M`
- Docling CLI preset used in pipeline: `granite_docling`

Run extraction from repo root:

```bash
modal run library/docling_pipeline/modal_app.py
```

Run a smoke extraction first:

```bash
modal run library/docling_pipeline/modal_app.py --max-docs 2
```
